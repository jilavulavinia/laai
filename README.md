# LAAI website

The website of Lavinia Lorena Jilavu (LAAI, AI for construction), Málaga.

Plain HTML, no build step. Netlify publishes the repository root, so every push to `main` goes live automatically.

- `index.html` – the main page
- `article.html` – "AI in AEC: From hype to actual work"
- `assets/` – images, video and the PDF guides
- `netlify.toml` – Netlify settings (publish folder, caching)
